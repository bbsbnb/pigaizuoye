# 知禾 · 三年级作业辅导助手

手机优先网页，单教师登录，SQLite 本地持久化，私有照片访问。未配置模型时不会返回模拟批改，仍可手动录入批改及生成报告。

## 运行

需要 Python 3.11 或以上。终端进入此目录：

```powershell
python -m pip install -r requirements.txt
python app.py
```

访问 http://127.0.0.1:8765，首次设置教师密码并确认授权。首次初始化仅在可信本机进行，不要把未初始化的应用开放到网络。

## 模型接入

公开仓库不包含密钥、学生数据或作业照片。首次部署可使用下方环境变量，或将 `model-config.example.json` 放到运行后生成的 `data/` 目录并命名为 `model-config.json`，填入自己的密钥。仅在核实隐私政策和取得授权后启用隐私审核开关。

本机已配置 Agnes 服务，地址 `https://api.agnes-ai.cn/v1`，模型 `agnes-3.0-flash`。密钥保存在不对外提供访问且被 Git 忽略的 `data/model-config.json`，不会发送给浏览器。环境变量优先于该文件。此文件包含敏感密钥，不要分享或上传。

已验证文本请求及 JSON 响应，尚未验证真实作业图片识别效果。用户于2026年10月23日确认已核实服务商隐私政策及取得必要授权，隐私审核开关已设为 `yes`，允许发送作业图片。学生姓名和性别仅保存在本系统，不作为额外字段发送给模型；图片中的个人信息需拍摄时遮挡。配置文件修改即时生效。

接入支持图片与 JSON 输出的 Chat Completions 兼容服务，模型由你自行选择，不预设供应商：

```powershell
$env:AI_BASE_URL = 'https://你的服务地址/v1'
$env:AI_API_KEY = '你的密钥'
$env:AI_MODEL = '你的视觉模型名称'
$env:AI_PRIVACY_REVIEWED = 'yes'
python app.py
```

设置最后一项前，请确认服务商对儿童作业图片的数据存储、训练用途、保留周期及所在区域的政策，取得必要授权。请求不额外传姓名，但照片本身可能含姓名，请拍摄时遮挡。接口凭证仅保留在服务器环境变量，不下发浏览器。模型结果必须由老师审核。

## 报告与使用边界

- 家长报告采用可追溯记录生成的保守规则草稿，不使用模型凭空扩写。日报约150字、周报约250字，实际长度随记录和老师观察变化，编辑器显示字数。不会截断观察或题目中的关键内容。
- 内部统计首次正确率，客观题部分正确计入分母但不计入完全正确；开放题不参与。订正不覆盖首次记录。
- 周报比较跨周重复的问题；上周出错的同科目知识点，本周至少有两条可判定记录且均正确时，描述局部表现改善，但不据此判断整体进步或退步。当前版本不提供自动难度归一化。
- 支持仅有订正的当天生成日报；同题复查按作业日期及确认时间选择本时段最新记录。历史订正没有确认时间时，同一天按现有存储顺序处理。
- 补拍前自动保存现有题目草稿，保存失败不继续补拍。报告切换和关闭页面前提示未保存编辑；保存单份报告不会清除其他报告的编辑。
- 自动草稿的老师观察按完整分句择取，日报观察追加预算以180字、周报以280字为上限。主体内容较长时不追加观察，不截断老师原始观察记录；主体及用户编辑内容仍可超过目标篇幅。
- 已确认的首次记录锁定。误确认需删除该批次后重新上传，会同时删除关联订正；请先记录需要保留的信息。
- 报告仅采用已确认、可判定的记录；生成后学生记录变化会保守标记其报告待更新，历史文本不自动覆盖。
- 老师观察中的明显数字、题数、分数和准确率句子会从自动草稿中排除，其余定性观察可以进入草稿。请审核后发送；老师自行编辑的报告不会被强行改写。
- 支持 JPG、PNG、WebP；不直接支持 HEIC。图片统一转为 JPEG 并移除 EXIF，长边最多2400像素。
- 手机拍照、相册多选及系统剪贴板需要在你的真实手机上进一步验收。桌面模拟移动视口不能替代真机。

## 手机访问和部署

默认只监听本机。可信局域网临时测试可设置 `$env:HOST='0.0.0.0'` 并通过电脑局域网 IP 访问；HTTP 不适合处理真实儿童资料，建议先使用无个人信息的测试图片。正式使用必须部署 HTTPS，并设置 `$env:COOKIE_SECURE='1'`；部署服务尚未选定。本版本不是已经上线的云服务。

运行数据在 `data/`（可用 `DATA_DIR` 修改），含密码哈希、会话密钥、数据库及照片，不应提交代码仓库或公开。停止服务后整体备份该目录并妥善加密保管。删除记录不自动清理外部备份。忘记密码尚无自助重置流程。
